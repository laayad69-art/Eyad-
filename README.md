# Eyad Alaa — Link Hub

صفحة شخصية واحدة (Single Page) تجمع روابط Eyad Alaa (@zmax__1 / ZMAX3).

## المحتوى

- `index.html` — الموقع بالكامل (HTML + CSS + JS في ملف واحد، بدون أي اعتمادات خارجية غير خطوط Google Fonts).

## المميزات

- Single Page، Mobile First، ريسبونسف بالكامل.
- تصميم بسيط أبيض/أزرق مع Glassmorphism خفيف.
- RTL كامل للعربي مع الحفاظ على الأسماء بالإنجليزية.
- كروت روابط بـ Hover animation و Glow، وكارت مميز لتطبيق ZMAX3.
- صورة الأفاتار مدمجة داخل الملف (base64) فمفيش أي ملفات خارجية مطلوبة.
